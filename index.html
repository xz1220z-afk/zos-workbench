数据来源与隐私

了解你的数据在哪里、如何被处理

💾 数据存储位置

ZOS 工作台中的所有数据（任务、收集箱、项目、指令队列）仅保存在当前设备的浏览器本地存储（localStorage）中。

  • 不会上传到任何云端服务器
  • 清除浏览器数据会导致工作台数据丢失
  • 不同设备之间的数据不互通

🔗 外部服务连接状态

  • ✗ 飞书 — 未连接
  • ✗ 腾讯文档 — 未连接
  • ✗ Obsidian — 未连接
  • ✗ 本地生活平台 — 未连接
  • ✗ 项目管理系统 — 未连接
  • ✗ 云存储 / 数据库 — 未连接

当前版本（v1.0.2）为纯本地工作台，所有外部服务状态均为「未连接」。

📋 数据收集声明

本工作台不收集任何用户数据，不包含任何埋点、统计或分析代码。PWA 离线缓存仅用于加速页面加载，不涉及用户数据。

🔄 数据迁移

需要更换设备或备份数据时，可在「设置」中使用数据导出/导入功能。导出的数据为 JSON 格式明文文件。

📝 业务数据说明

  • ✓ 任务数据：本地创建，本地保存
  • ✓ 收集箱：本地创建，本地保存
  • ✓ 项目数据：本地创建，本地保存
  • ✓ AI 指令：本地创建，本地保存

未标注「待接入」或「待确认」的内容均为用户手动录入的真实数据。

安装到手机桌面

ZOS 工作台已支持 PWA。添加到主屏幕后，可像原生 App 一样全屏运行。

iPhone（Safari）
打开 Safari → 点击底部「分享」按钮 → 选择「添加到主屏幕」
安卓（Chrome / Edge）
打开浏览器菜单 → 点击「安装应用」或「添加到主屏幕」
