数据来源与隐私

了解你的数据在哪里、如何被处理

💾 数据存储位置

ZOS 工作台的数据默认保存在当前设备的浏览器本地存储（localStorage）中；完成 Supabase 登录并手动同步后，可同步到你自己的云端项目。

  • 不会上传到任何云端服务器
  • 清除浏览器数据会导致工作台数据丢失
  • 不同设备之间的数据不互通

🔗 外部服务连接状态

  • ✓ 飞书 ERP — 万嘉与花火只读汇总服务已部署，首次刷新后在本机缓存
  • — 腾讯文档 — 尚未接入
  • — Obsidian — 本地 Build012 草稿桥接已验证；跨端只读索引已就绪（待首次同步）
  • — 本地生活平台 — 尚未接入
  • — 项目管理系统 — 尚未接入
  • — Supabase — 未配置，仅本机

云端同步需要先配置项目并完成邮箱登录；不会自动上传本地数据。

📋 数据收集声明

本工作台不收集任何用户数据，不包含任何埋点、统计或分析代码。PWA 离线缓存仅用于加速页面加载，不涉及用户数据。

🔄 数据迁移

需要更换设备或备份数据时，可在「设置」中使用数据导出/导入功能。导出的数据为 JSON 格式明文文件。

📝 业务数据说明

  • ✓ 任务数据：本地创建，本地保存
  • ✓ 收集箱：本地创建，本地保存
  • ✓ 项目数据：本地创建，本地保存
  • ✓ AI 指令：本地创建，本地保存

未标注「待接入」或「待确认」的内容均为用户手动录入的真实数据。
