# 万嘉 `#local-life` 增量升级审计（2026-08-08）

## 结论

- 保留现有 `#local-life` 路由、左侧导航、任务抽屉、商家诊断入口和其他公司模块。
- 原页面的 342 家商家、218 家动销、¥2,882,884 支付 GMV 来自旧林客读取链路，缺少“当日校验通过”证据，不能作为今日经营结果。
- 当前 Edge Function 仍只连接旧表 `01.04 商家管理（定时收集）`；新经营表的 table ID/字段契约尚未进入代码，因此本次先完成页面结构、可信状态、空状态和安全交互，不伪造实时数据。

## 原有能力

- `#local-life` 页面及万嘉来源状态栏。
- 三张旧 KPI 卡及商家列表。
- 商家名称/ID 搜索与诊断。
- 现有任务创建抽屉。

## 发现的问题

1. 历史快照没有醒目的日期、校验与可信状态，容易被当成今日数据。
2. 今日经营、运营待办、商家健康和增长机会没有分层。
3. 商家诊断未固定使用“证据—漏斗—假设—行动”结构。
4. 旧数据可能继续驱动今日动作，缺少可信数据闸门。

## 增量边界

- 旧数据仅放入带日期的“历史参考”区域。
- 只有同日且 `realtime_validated + passed` 的数据可进入今日 KPI、商家健康、待处理和机会池。
- 所有动作只生成本地任务草案，不自动派单、写飞书或执行服务动作。
- 其他页面、导航和已有用户数据保持不变。
