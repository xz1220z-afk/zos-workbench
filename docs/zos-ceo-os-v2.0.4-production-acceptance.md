# ZOS CEO OS v2.0.4 生产验收

## 发布范围

- 待我决策由只读清单升级为可执行工作台：采纳建议、交负责人、暂缓、确认解除、重新打开与查看来源。
- 所有处理记录保留历史；操作后可在 8 秒内撤销，不删除原始决策。
- 来源事实、AI 建议与正式处理动作分区展示；飞书仍是业务事实源。
- 增加搜索、公司/状态筛选、分段加载、右侧抽屉与手机底部操作面板。
- 全局交互统一为 44px 触控区、清晰焦点、克制动效，并支持“减少动态效果”。

## 数据边界

- 本次不迁移、不删除现有业务数据。
- 决策处理结果先保存到 ZOS 私有数据层；只有明确进入飞书预览并再次确认时，才允许执行单字段回写。
- 历史记录默认只显示 6 条，按需继续加载，避免 343 条历史同时渲染造成卡顿。
- 写入失败时保留当前抽屉和输入内容，不显示伪成功。
