# ZOS CEO OS v2.0.2 Data Durability Implementation Plan

> **For Codex:** execute in order with test-driven development; do not implement a step until its focused test fails for the expected reason.

**Goal:** Protect all user-created ZOS records across upgrades and imports with complete credential-free backups, non-destructive merge restore, automatic local checkpoints, and visible persistent sync protection status.

**Architecture:** Add a pure backup contract module for validation, legacy conversion, summaries, checksums, and safe merge. Add an asynchronous IndexedDB snapshot repository with an injectable in-memory adapter for tests. Wire both into the existing app/state-store runtime, replace legacy settings import/export handlers, and extend the health view without changing the Supabase schema.

**Tech Stack:** Vanilla ES modules, browser localStorage/IndexedDB APIs, Node built-in test runner, static GitHub Pages PWA.
