## 安全与刷新

- PWA 只能读取 Supabase 的公开 URL 与 anon key；不得保存飞书 App Secret 或 Obsidian 凭证。
- 飞书数据由 Supabase Edge Function 以只读方式拉取、聚合、缓存，再返回给已登录的 ZOS 用户。
- 默认刷新周期为 5 分钟；连接失败时保留最后一次成功数据，并明确标记更新时间。
- Obsidian 始终只读元数据，不读取或回写正文。
- 飞书默认只读。仅“负责人、状态、下一步、日期、审核状态”白名单字段可以进入预览；每条预览必须由朱帅确认，服务端执行后必须回读相同值才标记成功。
- 浏览器不持有飞书密钥或 Supabase `service_role`；审批和审计只有受保护的 Edge Function 可以修改。
