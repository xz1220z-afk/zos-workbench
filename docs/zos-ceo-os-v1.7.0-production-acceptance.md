# ZOS CEO OS v1.7.0 生产验收报告

> 日期：2026-08-03  
> 范围：富任务、今日执行、番茄专注、倒数日、日历视图、万嘉商家查询、花火档期查询、每日行业情报与四端响应式体验。

## 已实现

- 工作与生活双首页继续分离；桌面端保留完整导航，手机端固定“今日 / 日历 / 添加 / 专注 / 更多”五入口。
- 任务支持开始/截止时间、全天、优先级、公司、标签、项目、业务对象、执行人、提醒、重复、子任务和预计/累计专注时长。
- 专注计时按开始时间恢复，不用每秒写入本地或云端；完成后形成专注记录并更新绑定任务。
- 日历支持日、周、月、列表四视图，并可叠加倒数日与专注记录；个人忙碌只输出占位，不向公司视图暴露标题。
- 万嘉商家查询同时展示飞书事实、标准运营动作和本地待办；同名商家要求人工消歧，缺证据时显示“未记录”。
- 花火档期查询区分已占用、冲突、无记录证据与不可证明空闲，不用缺失数据冒充可预约。
- 情报中心独立展示最近 72 小时的万嘉、花火、玲丽及 CEO 关注情报，保留来源、事实、影响、建议和转任务入口。
- 登录后自动刷新业务、项目、情报、日历与私有同步；隐藏或离线时暂停远端请求，恢复后按新鲜度补拉。

## 真实性与边界

- 本地浏览器验收使用真实应用代码，但当前该本地来源未登录 Supabase，因此只验证界面、路由、状态表达和交互，不声称经营数据已完成登录态回读。
- 飞书 ERP、当前合同与原始业务表仍是金额、订单、项目和结算的事实源；ZOS 不用示例数字补空。
- 飞书经营数据、日历与 Obsidian 只读索引不会被前端直接写回；AI 输出、情报转任务和 CEO 简报均先进入本地/私有待审核状态。
- 正式生产登录态、Edge Function、RLS 与数据库迁移回读记录在下方生产部署章节完成后补充。
