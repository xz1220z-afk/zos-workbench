## 本版范围

- 现有工作台增量增加 Apple 风格交互层：统一按压、焦点、页面切换、减少动态效果、常用/全部导航与首页信息层级。
- 情报中心每张卡增加“问这条情报”，可在当前页面追问陌生概念。
- 问答只使用当前卡片和已载入情报，证据不足时明确提示；不上传问题、不调用未配置的模型、不修改情报记录。
- 增加版本备份、功能账本、验收记录和自动生产回读规则。
- 不迁移数据库，不更改飞书权限，不覆盖本机或云端用户数据。

## 已知边界

- 当前未配置独立 AI 模型密钥，因此问答是本地证据解释，不提供开放式联网百科搜索；这避免了把未知内容编造成答案。
- 要获得 Astra 等概念的完整定义，需要打开原始来源或后续增加经过明确授权的联网检索服务。
- 本版没有修改 Supabase 表、Edge Function 或飞书数据。

## 回滚

如生产验收失败，从 `zos-workbench-v2.3.1` 新建恢复分支并生成新的回滚提交，重新提升 Service Worker 缓存号后发布；禁止强推或删除用户数据。回滚后重新执行完整回归、三尺寸检查和生产资源回读。
