## 6. 后续完善优先级（不阻断 v1.6 发布）

1. **统一搜索与快捷指令**：继续复用当前设备已加载的数据，在一个入口检索三家公司、任务、项目、情报、日历和 Obsidian 元数据；每条结果必须标注权威来源与更新时间。
2. **数据新鲜度与失败重试**：在数据健康中心显示各来源的最后成功时间、缓存年龄、安全错误码和下次自动重试时间，避免把“旧缓存”误认为实时数据。
3. **情报到行动闭环**：保留“已读 / 忽略 / 转行动”，转行动后进入本人待审队列并关联公司与证据，不自动写飞书或知识库。
4. **CEO 周报复盘**：按事实生成收入、项目、风险、情报和行动完成率的周度草稿；人工确认后才沉淀长期结论。
5. **外部日历真实接入**：取得本人 ICS 订阅地址后完成冲突、空档和今日安排验收；工作端只显示生活事件的忙碌时段。
