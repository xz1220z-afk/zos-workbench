# ZOS 首页表达与触感升级设计

**日期：** 2026-08-08  
**范围：** 仅现有“工作首页”（`#dashboard`）与“生活首页”（`#life`）的首屏表达、信息层级、状态反馈与响应式排版。  
**不在范围：** 左侧导航、路由、飞书/Supabase/Obsidian 数据边界、业务页面、任务/日历的写入逻辑。

## 目标

让首页从固定口号页变成每天可用的“当日变化面板”：

- 工作首页回答：今天有什么变化、需要我拍板什么、下一步是什么。
- 生活首页回答：今天的生活节奏、值得留心的人和事、未来的重要提醒。
- 交互保持深色 CEO OS 风格，但采用短促、克制、可中断的触感反馈；不以大幅动画制造“高级感”。

## 设计原则

1. **变化优先，不说空话。** 首屏标题来自已存在的只读状态模型；无变化时也使用平静、具体的节奏提示，禁止每日固定复读同一句激励话。
2. **工作与生活使用不同语气。** 工作页使用事实、行动、决策；生活页使用时间、能量、关系与仪式提醒。生活隐私仍只在生活区显示。
3. **层级少而明确。** 首屏只保留一个主动作、两个次动作；将完整的经营/知识/系统细节保留在现有卡片和各模块内。
4. **动作必有反馈。** 点击、加载、成功、失败、不可用均有可读文字状态；动效不承载唯一信息。
5. **保留真实数据边界。** 缺数据显示待同步/待校验；历史快照继续带日期与来源，绝不写入模拟经营数。

## 工作首页：变化驱动的 CEO Brief

### 首屏内容

替换“CEO 指挥中心”等静态标题为 `今日简报`，并由现有模型生成一个有限状态标题：

| 状态 | 标题格式 | 说明 |
| --- | --- | --- |
| 有 P0/P1 决策 | `今天有 N 件事需要你拍板` | 只计入现有决策/风险模型中的真实条目。 |
| 有临期/异常 | `今天有 N 个节点值得优先处理` | 展示临期、同步异常或风险的聚合，不虚构原因。 |
| 有已识别机会 | `今天有 N 个可转行动的机会` | 仅使用已存在的情报/机会池结果。 |
| 无显著变化 | `今天的节奏已排好` | 不使用鼓励口号，显示下一个日程和可用专注时间。 |

副文案固定为事实摘要，例如“1 个交付临期 · 1 个数据待核验”，无法确认时显示“部分来源未更新，见同步状态”。

### 首屏动作

- 主动作：按当前状态跳转到 `待我决策`、`今日视图` 或 `日历中心`。
- 次动作：快速收集、新建任务；沿用已有入口及权限。
- 删除“刷新”作为视觉主按钮，保留为低强调同步状态操作。

### 首屏下方

保留现有概览、Top 3、待我决策、三家公司经营全景、行业情报、日程与系统健康模块；只调整为“现在值得处理 → 经营全景 → 今日信息 → 日程与健康”的阅读顺序。任何缺数据卡保持真实空状态。

## 生活首页：私人节奏面板

### 首屏内容

替换“把生活安排好，工作才有稳定的能量”等静态宣言。标题同样按状态产生：

| 状态 | 标题格式 |
| --- | --- |
| 当天有私人安排 | `今天留给自己的时间还有 N 段` |
| 7 天内有重要日期 | `未来 7 天有 N 个值得提前准备的日子` |
| 有关怀草稿 | `今天有一件关怀小事可以完成` |
| 无已知事项 | `今天可以给自己留一点空间` |

副文案继续明确“仅自己可见”。仅展示已授权的本地私密元数据；不读取聊天正文、定位、健康病历、财务明细或关系猜测。

### 内容结构

1. 今天的生活：今日安排/关怀草稿/精力事项。
2. 未来 7 天：已存在重要日期与仪式提醒。
3. 生活领域：健康、关系、成长、财务、出行等已存在的摘要入口。
4. 轻量记录：沿用“记录生活事项”，不自动创建外部日历或外发消息。

## 苹果式触感与视觉系统

### 视觉

- 深色基底保持不变；减少同色、同权重的“方形大卡”。
- 首页首屏采用一块有层次的深色材质面板，使用极弱的暖金/深蓝光晕作为方向，而非图片背景。
- 数字卡降为辅助信息；主信息放大、留白增加、文字行长缩短。
- 状态采用文本 + 色点 + 图标，不只靠颜色。
- **液态玻璃只用作浮层材质。** 顶栏、工作/生活首页简报、主操作按钮和抽屉使用轻量的半透明层、背景模糊、边缘高光和低强度渐变；每屏不超过三个玻璃层。KPI、任务列表、商家健康表、情报正文和长滚动区域保持清晰的深色实体面，不使用折射或强模糊。
- 当前工程是原生静态 PWA，不引入 React 或实时 WebGL/SVG 着色器组件。液态玻璃以原生 CSS、渐进增强与功能检测实现；不支持 `backdrop-filter`、低性能设备或用户开启“减少动态效果”时，自动退化为静态深色半透明面。

### 交互

- 可点击卡片：`120–180ms` 的轻微压下（`scale(0.985)`）与边框/材质高亮；鼠标、键盘和触摸反馈一致。
- 路由切换：内容短淡入，不整页滑动；可立刻再次操作。
- 异步动作：按钮内联显示“正在刷新/已更新/需重试”，不得只显示 toast。
- `prefers-reduced-motion` 下关闭位移与渐变动画，仅保留颜色与文本状态。
- 焦点环、键盘操作与点击区域不缩小，确保移动端与桌面端一致。
- 玻璃材质不随鼠标持续追踪、不持续 `requestAnimationFrame`，仅在悬停/按压时触发一次短反馈，避免拖慢首屏与日历等高密度页面。

## 数据与安全

- 本次不新增外部数据读取、不修改飞书、不写 Vault、不创建日历或自动化。
- 首页仅消费既有运行时模型；无数据即明确空状态。
- 私人生活条目不能进入工作首页、公司页面、团队日报或共享导出。

## 验收

1. 工作、生活首页均没有每日固定口号；同一天的数据状态变化会反映到首页标题和副文案。
2. 现有导航、路由、数据源状态、卡片入口与页面功能不消失。
3. 工作/生活首屏的主动作可用，空状态、加载和错误状态可读。
4. 桌面、平板、手机无横向溢出；键盘焦点与触摸点击可用。
5. `prefers-reduced-motion` 下不依赖动画传达状态。
6. 现有全量测试、针对首页的新增测试和三尺寸视觉验收通过后才上线。

## 回滚

本次仅替换首页渲染文案、布局样式和局部交互。若回归，可回退至实施前 Git 提交；不会影响本地任务、同步索引、日历、Agent 或远端事实源数据。
