# Agent OS 管理与调用中心设计

## 目标

在现有 `#agent-workbench` 页面内增量升级 Agent 管理能力，不新增工作台、不改变现有导航、业务数据结构或视觉系统。工作台仅保存 Agent OS 的只读索引；Vault、飞书和外部系统始终保持不写入。

## 已审计现状

- 现有页面已有 Agent 卡片、执行记录、草稿审核链、任务抽屉和知识入口。
- Agent 卡片来自代码内固定目录，尚未读取 Vault。
- Agent OS 实际存在于 Enterprise Brain，包含 Agents、Skills、Workflows、Evaluations、Logs、Runbooks。
- 正式站为静态网页，不能在未授权的情况下直接读取本机目录；现有产品已有本机元数据扫描并导入的模式。
- Vault 当前有大量用户未提交改动，本次只能只读扫描。

## 增量架构

### 1. 本机只读索引生成器

新增 `scripts/agent-os-index-scan.mjs`。脚本仅读取指定 Agent OS 根目录，识别带有下列主键的 Markdown：

- `agent_id`
- `skill_id`
- `workflow_id`
- `evaluation_id`

评估、日志和调用卡若没有专用 ID，则仅生成文件级证据索引。输出只包含：相对路径、文件哈希、修改时间、允许展示的前置属性、章节摘要和关联 ID；不复制正文，不写回 Vault。

### 2. 浏览器索引存储

新增本地私有集合 `agent_os_indexes`，只保存最近一次导入的索引快照；新增 `local_agent_tasks` 保存 REL-001 等私密 Agent 任务。两者可进入用户主动导出的本地安全备份，但明确排除在 Supabase 跨端同步之外，且不包含 Vault 正文。其他 Agent 任务只保存最小 Agent 引用，不把身份卡路径、哈希、知识入口或证据清单带入云端。旧数据模型兼容迁移，不改写现有 Agent 执行记录。

### 3. Agent OS 总览

保留 Agent 工作台页面，在现有 Hero 下增加：

- 巡检摘要；
- 五类筛选；
- 动态 Agent 卡片；
- 详情抽屉；
- 原有执行记录和审批链。

五类由身份卡元数据、Agent ID 前缀和明确名称规则组合归类：总控与共享中台、万嘉网络、花火影像、玲丽教育、我的生活。归类只影响展示，不改 Agent 文件。

### 4. 调用链

“立即调用”不执行 Agent。它将选中 Agent 的 ID、职责、边界、Skill、知识入口和输出契约临时装入现有任务抽屉，状态固定为草稿/只读分析。用户补充具体任务后才保存；所有 Agent 都强制按“事实、推断、建议、待确认、下一步”输出，身份卡自带格式作为补充。普通 Agent 持久化时只保留最小引用，REL-001 任务只保存在本机。

### 5. 详情与证据

详情抽屉展示身份卡允许公开的章节摘要及关联 ID：使命、范围内、范围外、禁止动作、Skill、知识入口、Workflow、评估、日志、Pilot、最近变更和调用示例。没有证据时显示“缺少证据”，绝不推断为已上线。

### 6. REL-001 私密隔离

- `REL-001` 只在“我的生活 > 私密关系”筛选内出现；默认总览和公司分类不出现具体内容。
- 索引不包含私密聊天、性隐私、定位、账号、密码、未确认猜测、私人财务或医疗细节。
- 详情仅显示三类本地提醒草稿：每日关怀、每周复盘、重要日期 7/3/0 天提醒。
- 不发送消息、不下单、不转账、不预约、不创建公开日历。

### 7. 巡检

- 页面打开时检查已导入索引并与上一快照比较。
- 有索引时显示总数、状态、变更、停用、缺失证据和风险。
- 无结构变化显示“Agent OS 无结构变化。”
- 浏览器没有本地目录权限，首版提供“导入/刷新索引”按钮，不引入外部定时服务。
- 现有自动刷新机制只负责云端事实源，不让它读取本地 Vault。

## 安全边界

工作台只允许扫描、索引、展示、搜索、分析、草拟、预览和提醒草稿。任何 Vault 修改、飞书写入、消息发送、发布、自动化启用、日历创建、付款、预约、权限修改、删除、归档、批量移动或改名都不在本次实现范围。

## 验收

1. Agent 来源为导入索引，不再依赖固定卡片数量。
2. 五类筛选完整，REL-001 仅在私密个人区。
3. 详情抽屉显示职责、状态、Skill、知识入口、调用示例和证据。
4. 调用进入现有任务抽屉，固定为草稿/只读分析。
5. 巡检不修改 Vault、飞书或外部系统。
6. 原执行记录、审批链、任务、知识、路由和用户数据均保留。
7. 桌面、平板、手机无横向溢出，键盘焦点和关闭交互可用。
