# ZOS v1.7 个人执行与经营查询版设计规格

**状态：** 已批准（方案 A）  
**批准日期：** 2026-08-03  
**目标：** 在现有 ZOS CEO OS 中增加滴答式个人执行能力、花火档期查询和万嘉商家经营档案，并保持飞书事实源只读、个人数据本人可见、四端一致。

## 1. 产品边界

- 飞书 ERP 是万嘉、花火、玲丽业务事实的权威来源；工作台默认只读聚合。
- Supabase `zos_records` 保存本人任务、日程、倒数日和专注记录，继续使用 owner RLS。
- Obsidian 只提供知识元数据，不替代实时业务记录。
- 不伪造缺失字段，不把“未记录”显示成“未完成”，不自动派人或回写飞书。
- PWA 支持桌面、平板、iPhone 和 Android；移动端保留五个主导航位。
- 现有自动刷新、离线缓存、登录、冲突处理、每日情报和三公司经营模块必须保持兼容。

## 2. 信息架构

### 桌面导航

1. 工作首页 / 生活首页
2. 今日执行
3. 任务中心
4. 专注中心
5. 日历与倒数日
6. 情报中心
7. 万嘉网络（内含商家经营档案）
8. 花火影像（内含档期查询）
9. 玲丽教育、企业项目、企业大脑、复盘及其他既有中心

### 移动端导航

- 今日
- 日历
- 快速添加
- 专注
- 更多

“更多”继续承载公司页、情报、搜索、复盘、设置等次级入口。

## 3. 丰富任务模型与快速添加

任务字段：

- `title`、`description`、`status`
- `startAt`、`dueAt`、`dueDate`、`allDay`
- `priority`（0–3）、`tags[]`、`listId`
- `company`（`ceo|wanjia|huahuo|lingli|life`）
- `projectId`、`businessEntityId`、`businessEntityType`
- `assignee`、`estimateMinutes`
- `reminderAt`、`recurrence`
- `subtasks[]`（稳定 id、标题、完成状态）
- `attachments[]` 仅保存名称、类型和安全 URL 元数据，不保存凭证或正文
- `focusMinutes`、`focusCount`

快速添加使用一个响应式抽屉：标题与说明始终可见；日期、优先级、标签、清单、公司、关联对象、提醒、重复、预计时长、子任务在“更多”中展开。保存到任务后进入四端同步；“先收集”仍可保存到 Inbox 待整理。

## 4. 今日执行与一天行程

- 顶部显示今日日期、完成进度、专注时长和冲突数量。
- 按“全天、上午、中午、下午、晚上、未安排”分组。
- 有具体时间的事项进入纵向时间轴；无时间任务保留在待安排区。
- 汇总本人任务、本人日历、飞书日历和公司业务节点。
- 私人事件进入公司上下文时只显示“个人安排”。
- 今日 Top 3 沿用确定性优先级：逾期 > 今日到期 > 高风险业务 > 时间冲突 > 高分情报。

## 5. 番茄专注

- 默认 25 分钟专注 / 5 分钟休息，支持 50/10 和自定义 1–180 分钟。
- 状态机：`idle -> running -> paused -> completed|cancelled`。
- 可绑定任务；完成后累计任务 `focusMinutes` 与 `focusCount`。
- 专注会话保存开始、结束、计划时长、实际时长、绑定任务和完成状态。
- 计时依赖绝对时间戳，刷新页面后按时间戳恢复，不依赖持续 `setInterval` 计数。
- 浏览器通知只在用户已授予权限时发送，绝不自动弹出权限请求。

## 6. 日历与倒数日

- 日、周、月、列表四种视图。
- 日/周视图使用真实时间轴；月视图展示每日事件数量、倒数日和冲突标记。
- 可按公司、个人、优先级筛选；可切换已完成任务、专注记录和倒数日。
- 倒数日支持单次和每年重复，展示剩余/已经过天数；私有倒数日不进入公司视图。
- 现有飞书日历和 ICS 只读事件继续自动同步。

## 7. 花火档期查询

输入日期或日期范围后返回：

- 项目/订单、客户、拍摄日期、开始/结束时间、地点、状态
- 项目负责人、项目成员及角色
- 按人员 × 日期/时间段形成占用矩阵
- 重叠项目、未分配人员、缺少时间、缺少地点分别提示
- 私人日历只以“忙碌”参与冲突判断，不暴露标题

结果只基于飞书项目和日历的可证明字段。若源表只有拍摄日期而没有开始/结束时间，显示“全天/时间未录入”，不推断具体时段。档期查询不执行人员分配。

## 8. 万嘉商家经营档案

支持商家名称模糊搜索与同名消歧。选中商家后展示：

- 基本状态、负责人、合作模式、最近更新时间、下一步动作
- 是否上团、是否动销、经营分
- 支付/核销/退款 GMV 与券数（仅有真实字段时显示）
- 已完成动作、待完成动作、逾期动作、未记录字段四类状态
- 关联任务、项目、内容/直播动作与按时间排序的运营轨迹
- 数据新鲜度、风险和证据来源

“已完成/未完成”只由显式状态或已确认检查清单判定；没有记录的内容归入“未记录”，不得显示为未做。

## 9. 每日行业情报

- 保留独立情报中心和首页 3–5 条今日必看。
- 继续按万嘉、花火、玲丽、CEO 分组。
- 事实、影响、建议、来源和更新时间分开呈现。
- 支持已读、忽略和转任务；转任务时打开丰富任务抽屉并带入来源关联。

## 10. 数据与迁移

- `zos_records.entity_type` 增加 `focus_sessions`、`countdowns`。
- 本地状态升级为 v1.7，保留 v1.4 的所有记录、revision、deviceId 和 tombstone。
- 丰富任务字段作为 JSON payload 兼容扩展，不破坏旧任务。
- 花火只读 payload 增加 `startAt/endAt/location/owner/members/roles`。
- 万嘉只读 payload 增加可证明的经营指标与动作状态；正文字段仍禁止进入缓存。
- Service Worker 更新缓存版本并包含所有新增模块。

## 11. 失败与空状态

- 未登录：显示登录要求，不无限加载。
- 飞书缺字段：显示字段缺口，不整页 502。
- 缓存陈旧：显示上次成功数据和更新时间。
- 离线：个人任务、倒数日和番茄钟继续可用；公司查询显示缓存。
- 无档期：明确“该日无已记录安排”；不能写“所有人有空”。
- 无商家匹配：提供相似名称，不显示示例商家。

## 12. 验收标准

1. 新旧任务均可打开、保存、完成、同步，不丢 revision 或 tombstone。
2. 番茄钟可开始、暂停、恢复、刷新恢复和完成，并正确累计绑定任务。
3. 今日执行按时间段排序，私人事项在公司上下文被脱敏。
4. 倒数日单次/年度重复计算正确，日/周/月/列表视图均可访问。
5. 花火档期在日期查询中显示真实项目和人员，能识别冲突、未分配和缺失时间。
6. 万嘉搜索能消歧并分开展示已完成、待完成、逾期和未记录动作。
7. 情报可转为带来源的丰富任务。
8. 四端响应式导航、触控尺寸、离线缓存和登录状态保持可用。
9. 所有新增数据保持本人 RLS；业务查询无自动写回飞书。
10. 三轮验收分别覆盖单元/契约、全量回归/构建、生产部署/真实页面回读。
