# ZOS 智能日历重构设计规格

**状态：** 待最终复核（方案 A 已口头确认）

**设计日期：** 2026-08-03

**目标：** 把现有仅能简单新建和展示的日历中心，升级为适合朱帅个人与三家公司使用的四端智能日历；借鉴滴答清单的高频交互，但保持飞书事实源只读和 ZOS 本地数据可恢复。

## 1. 产品边界

- ZOS 本地创建的日程可新建、编辑、删除、复制、拖动改期、跨多日、重复和设置提醒。
- 本地日程通过现有 Supabase `zos_records` 与 owner RLS 在电脑、平板、iPhone、Android 间同步。
- 飞书日历、ERP 项目、任务、情报跟进、倒数日和专注记录作为聚合图层显示；源数据默认只读。
- 飞书事件的详情页提供“打开来源”，不在 ZOS 内直接删除或回写飞书。
- 删除采用 tombstone 与回收站，默认可恢复；不做立即物理删除。
- 离线时允许编辑本地日程，恢复联网后走现有 revision/deviceId 冲突合并。
- 私人日程进入公司上下文时只暴露“个人安排/忙碌”，不显示标题与备注。

## 2. 推荐交互结构

### 顶部导航

- “今天”快捷返回当前日期。
- 上一周期、下一周期按钮；周期随日/周/月视图变化。
- 当前日期或月份标题可点击打开日期选择器。
- 显示最近同步时间、同步中、离线、部分失败等真实状态。
- 主操作保留“新建日程”，次操作包含“同步当前范围”和“回收站”。

### 视图

- 日视图：全天区域 + 24 小时时间轴，适合当天排程。
- 周视图：7 天时间轴，显示跨日条、冲突和空闲区间。
- 月视图：固定 6 周网格；跨日事件横跨对应日期，事件过多时显示“还有 N 项”。
- 列表视图：按日期连续加载，适合手机端快速查看与搜索。
- 桌面端保留侧栏；手机端使用顶部日期条、底部主导航和触控友好的详情抽屉。

## 3. 日程编辑器

新建和编辑共用一个响应式抽屉，不再使用连续 `prompt()`。

基础字段：

- 标题
- 开始日期/时间、结束日期/时间
- 全天、跨多日
- 公司/场景：CEO、万嘉、花火、玲丽、个人
- 隐私：工作、私密
- 备注

高级字段：

- 重复：不重复、每天、每周、每月、每年、自定义间隔与星期
- 重复结束：永不、指定日期、指定次数
- 提醒：无、事件时、提前 5/15/30 分钟、1 小时、1 天、自定义
- 颜色/图层
- 来源链接（只保存安全 URL，不保存凭证）

校验规则：

- 标题与开始时间必填。
- 结束时间不得早于开始时间。
- 全天事件按日期区间计算，结束日期采用用户可理解的包含式展示。
- 私密日程必须归属本人，不允许被公司数据视图展开。

## 4. 详情、编辑与删除

- 点击任意事件打开详情抽屉，不直接进入编辑状态。
- 本地日程显示：编辑、复制、删除、创建关联任务。
- 飞书/ERP 等外部事件显示：打开来源、复制为本地日程；不显示删除按钮。
- 删除本地日程前显示二次确认，成功后进入回收站。
- 回收站支持恢复；过期物理清理由后续独立策略处理，本版本不自动清空。
- 重复日程编辑或删除时提供“仅本次 / 本次及以后 / 整个系列”。

## 5. 跨多日、拖动与快速添加

- 月/周视图中的跨多日事件在每个覆盖日期可见，并以连续条表达。
- 在月视图从某日拖到另一日，可预填一个跨多日全天事件。
- 拖动本地事件到新日期可改期；调整日/周时间轴上的上下位置可改时间。
- 桌面端支持拖动；移动端使用长按后选择“改期”，避免触摸误操作。
- 双击桌面日期或点击移动端日期后的“＋”可快速新建并自动带入日期。
- 所有拖动变更先在界面预览，保存成功后才进入同步队列；失败则恢复原位置并提示。

## 6. 重复日程模型

本地日程新增兼容字段：

- `recurrenceRule`：结构化重复规则
- `seriesId`：重复系列 ID
- `originalStartAt`：实例原始时间
- `exceptionType`：`modified|cancelled`
- `reminders[]`

渲染时仅展开当前可见范围与少量预取缓冲，不提前生成无限实例。单次修改保存为例外记录，系列规则保持稳定。旧日程无上述字段时继续作为单次事件使用。

## 7. 日期范围拉取与自动同步

- 前端根据当前视图计算可见范围：日视图 1 天、周视图 7 天、月视图 42 天、列表视图按分页窗口。
- 向 Edge Function 传递 `start`、`end`；服务端校验最长范围，防止无限拉取。
- 预取当前范围前后一个周期，切换日期时优先展示缓存，再后台增量刷新。
- 同一范围在短时间内去重请求；快速连续翻页只保留最后一次有效结果。
- 自动刷新、手动“同步当前范围”和全局自动同步共用一个状态机，不重复发起并行请求。
- 飞书返回内容只进入外部日历缓存，不写入本地可编辑集合。
- 拉取失败时保留最后一次成功缓存，明确显示失败来源与上次更新时间。

## 8. 数据归属与操作矩阵

| 来源 | 展示 | 本地编辑 | 本地删除 | 四端同步 | 打开来源 |
|---|---:|---:|---:|---:|---:|
| ZOS 本地日程 | 是 | 是 | 回收站 | 是 | 可选 |
| 飞书日历 | 是 | 否 | 否 | 自动拉取 | 是 |
| ERP 项目/任务 | 是 | 否 | 否 | 自动拉取 | 是 |
| 本地任务 | 是 | 去任务中心 | 否 | 是 | 是 |
| 情报跟进 | 是 | 去情报中心 | 否 | 是 | 是 |
| 倒数日 | 可切换 | 去倒数日编辑 | 去倒数日 | 是 | 是 |
| 专注记录 | 可切换 | 否 | 否 | 是 | 是 |

## 9. 冲突、并发与恢复

- 时间冲突只提示，不自动移动或覆盖日程。
- 同一设备连续编辑使用最后一次本地保存。
- 多设备同时编辑继续使用 revision/deviceId 合并；发生不可自动判定的冲突时保留双方版本，并要求用户选择。
- 删除 tombstone 的 revision 高于旧实体时，其他设备不得复活旧版本。
- 飞书缓存与本地日程 ID 使用不同命名空间，避免同 ID 覆盖。
- 网络失败、配额不足或存储受限时不得出现空白页；日历先显示本地/缓存数据和降级提示。

## 10. 性能要求

- 首屏不等待飞书拉取完成；先渲染本地状态和上次缓存。
- 月视图只渲染当前 42 天和每格受限数量，剩余事件通过“还有 N 项”展开。
- 重复实例按可见范围生成，外部结果按范围缓存。
- 事件拖动期间不触发整页重绘和远程请求。
- 移动端首次可交互不被日历同步阻塞。

## 11. 空状态与错误状态

- 未登录：本地日历仍可用，云同步显示“登录后同步”。
- 飞书未配置：本地日历正常，外部图层显示配置提示。
- 当前范围无外部事件：明确“该范围暂无飞书日程”，不表示所有人空闲。
- 同步失败：显示失败来源、上次成功时间和重试按钮，不清空旧数据。
- 删除失败：恢复原记录并保留编辑内容。
- 冲突：显示冲突卡片，允许查看两个版本后选择。

## 12. 实施边界

本版本包含：

- 本地日程完整 CRUD、详情抽屉与回收站恢复
- 日/周/月/列表日期导航
- 跨多日展示与创建
- 重复日程和提醒数据模型
- 桌面拖动改期、移动端长按改期
- 按可见日期范围拉取飞书日程
- 缓存优先、后台刷新与四端 Supabase 同步
- 响应式和无障碍基础支持

本版本不包含：

- ZOS 直接回写、删除飞书日历
- 团队成员共享编辑
- 复杂会议室与参与人邀请
- 自然语言 AI 自动排程
- 自动物理清空回收站

## 13. 验收标准

1. 本地日程可新建、查看、编辑、复制、删除、恢复，并在四端同步后保持一致。
2. 单日、跨多日、全天和定时事件在日/周/月/列表视图显示正确。
3. 日历可返回今天、前后翻页、选择任意日期，切换视图保持合理锚点。
4. 重复日程按可见范围展开；“仅本次/本次及以后/整个系列”的修改与删除不互相污染。
5. 飞书按当前可见范围拉取，切换范围先显示缓存，再增量更新。
6. 飞书/ERP 事件无编辑和删除入口，本地日程具有完整操作入口。
7. 删除生成 tombstone，恢复后生成更高 revision；离线删除联网后能正确同步。
8. 拖动本地事件可改期，保存失败时恢复原位置；外部事件不可拖动。
9. 私密事件在公司上下文只显示“个人安排”，不暴露标题、备注和提醒。
10. 无数据、未登录、离线、飞书失败和存储受限时均不出现空白页。
11. 全量自动化测试通过，并进行三轮验收：单元/契约、完整回归/构建、生产部署/真实页面回读。

## 14. 成功判定

用户不再需要进入每家公司页面逐个刷新日历，也不再通过多个弹窗录入日程；日历中心可作为统一入口管理本人日程、查看三家公司事实节点，并在四端保持可恢复、可追踪的一致状态。
