# ZOS AI Office 运行闭环设计规格

**状态：** 已确认执行  
**目标版本：** v2.12.0  
**基线：** v2.11.0 / commit `e47a136`  

## 1. 目标

把现有 AI 优先首页、Agent OS、任务、目标和 C 级受控执行连接成一个可见闭环，而不是新增第二套工作台。用户通过现有文字或语音入口提出目标，系统继续使用现有意图路由和 Agent；本次只增加三项缺口：AI 办公室态势、统一执行账本、长期事项推进提示。

## 2. 现状审计

已存在并复用：

- 首页文字／主动语音入口、ChatGPT 回答和实时语音；
- 规则优先意图路由、万嘉／花火／玲丽／生活／知识来源隔离；
- Agent OS 动态身份卡、组织与部门目录、独立规则、上下文候选和任务记录；
- L0 查询、L1 可撤销草案、L2 精确预览；
- Agent 执行记录、目标、任务、审计日志和四端私有同步；
- 独立登录页、唯一业主校验和现有数据耐久性保护。

当前缺口：

1. Agent 卡片能展示身份，但不能集中说明“谁正在做什么、等待什么、是否异常”；
2. AI 命令、Agent 任务和审批记录分散，缺少统一、可回读的执行时间线；
3. 目标、逾期任务和 AI 下一步尚未形成一个“防遗忘”提示面板；
4. 能力边界存在于代码和文案中，但缺少面向用户的工具／权限说明。

## 3. 产品结构

### 3.1 AI 办公室态势

在现有 Agent OS 页面增加“AI 办公室态势”。数据动态来自 Agent 身份索引、`agent_runs` 和 `agent_task_archives`，按现有组织与部门展示：

- Agent 名称和 ID；
- 当前状态：空闲、草稿、待确认、处理中、已完成、异常；
- 当前任务或最近任务；
- 最近更新时间；
- 可用动作：查看详情、派任务、只读分析。

状态必须由记录规则计算，不得把 draft/pilot 身份卡误显示为在线执行。

### 3.2 统一执行账本

在 Agent OS 页面增加“执行账本”。账本仅汇总现有脱敏记录：

- AI 命令活动；
- Agent 执行记录；
- Agent 任务归档；
- 待确认审批。

每条展示类型、范围／Agent、状态、时间、摘要和下一可用动作。不得存储原始音频、Vault 正文、飞书原始行、密钥或完整私人对话。删除仍沿用现有人工确认；本次不增加自动清理。

### 3.3 防遗忘推进提示

首页增加“AI 推进提醒”，规则读取现有目标、逾期／无下一步任务和最近 Agent 结果：

- 目标存在差距但没有对应开放任务；
- 任务逾期或缺少截止时间；
- Agent 结果已完成但没有后续任务；
- AI 给出下一步但尚未保存为草案。

提示只生成建议，不自动创建任务。用户点击后进入现有任务草案或现有页面。

### 3.4 工具与权限说明

Agent OS 展示当前工作台已经真实接入的能力：业务只读、知识检索、浏览器语音、OpenAI 回答、实时语音、本地草案、飞书变更预览。每项标注 L0/L1/L2 及当前可用状态；不得显示未安装或未验证的插件为可用。

## 4. 数据与安全

- 不新增第二套业务数据；新视图从现有集合派生。
- AI 命令账本只保存 `sanitizeAiActivity` 的安全字段，可增加非正文的 `intent`、`agentId`、`riskLevel`、`updatedAt` 和安全状态。
- REL-001 及私密个人 Agent 不在跨组织态势中显示任务摘要；只显示“私密任务”及状态。
- L2 永远只显示预览，仍需屏幕点击确认；语音确认不能执行高影响动作。
- 工作台不自动修改 Vault、飞书、日历、权限、消息、发布、付款或合同。

## 5. 组件边界

- `src/app/ai-office.mjs`：Agent 当前态势纯模型。
- `src/app/execution-ledger.mjs`：脱敏执行时间线纯模型。
- `src/app/continuity-engine.mjs`：防遗忘推进提示纯规则。
- `src/app/views/agent-workbench-view.mjs`：增量渲染态势、账本和能力边界。
- `src/app/views/dashboard-view.mjs`：增量渲染最多四条推进提醒。
- `src/app.mjs`：装配现有集合、保存安全 AI 活动、复用既有动作。

## 6. 验收

1. Agent 数量、组织、状态和任务均动态派生，无模拟数字；
2. 私密 Agent 不泄露任务摘要；
3. 执行账本能区分待确认、执行中、完成、失败和草稿；
4. 防遗忘提示只建议，不自动创建或外发；
5. 工具说明只展示已接入能力及真实风险等级；
6. 既有导航、登录、语音、公司页面、Agent 详情、任务和用户数据不受影响；
7. 自动化测试、语法检查、PWA 版本一致性、桌面／平板／手机验收全部通过；
8. 发布前保留 `zos-workbench-v2.11.0-pre-ai-office` 回滚标签。

## 7. 回滚

代码回滚到 `zos-workbench-v2.11.0-pre-ai-office`，并提升 Service Worker 缓存世代。回滚不删除或改写任务、Agent、日历、同步记录和公司经营数据。
