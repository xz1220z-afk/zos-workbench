# ZOS v1.10 日历任务闭环设计

日期：2026-08-06  
状态：按用户授权的产品经理判断进入实施  
范围：ZOS 自建任务与日程；飞书、ICS、业务项目等外部事实源保持只读

## 一、三轮产品复盘

### 第一轮：数据安全与跨端一致性

- 删除不是物理删除，而是把记录转为带 `deletedAt`、`revision`、`deviceId` 的墓碑。
- 墓碑沿用现有 Supabase `zos_records` 同步链路传播；另一端拉取后必须移除活跃任务，不能“删了又回来”。
- 删除后保留回收站恢复能力；恢复会产生更高 revision，再次同步到其他端。
- 外部飞书日历、ICS、业务项目只读，界面不出现删除和拖动入口。

### 第二轮：日常效率

- 日历中的任务打开后直接提供：完成/恢复待办、编辑、复制、改期、删除。
- 任务中心也提供删除入口，操作语义与日历完全一致。
- 删除前显示明确确认页；删除后显示“已移入回收站”与撤销入口。
- 改期保持原任务时长；月视图拖动到新日期即可调整，手机端继续用详情操作。

### 第三轮：四端可用性与状态透明

- 电脑：点击详情、拖动改期、键盘可达按钮。
- 手机/平板：详情抽屉和底部动作按钮，不依赖悬停。
- 日历提供“全部 / 任务 / 日程 / 三家公司 / 个人”快捷筛选，减少信息噪音。
- ZOS 本地任务与日程显示“待同步 / 已同步 / 冲突”状态；外部来源显示“只读来源”。

## 二、最终范围

### P0 必须上线

1. ZOS 自建任务在日历详情和任务中心均可删除。
2. 删除必须二次确认并生成同步墓碑。
3. 统一回收站展示任务与日程，均可恢复并再次同步。
4. 删除后提供一次即时撤销。
5. 日历内任务支持完成、编辑、复制和改期。
6. 所有外部来源保持只读，不出现破坏性操作。

### P1 同批上线

1. 日历快捷筛选：全部、任务、日程、万嘉、花火、玲丽、个人。
2. 本地记录展示同步状态，冲突优先显示。
3. 桌面端拖动任务改期，保持持续时间；无截止时间时只调整开始时间。

### 暂不做

- 不删除或回写飞书原始任务、飞书日历、ICS 订阅或 ERP 项目。
- 不做永久清空回收站，避免误删不可恢复。
- 不引入新的数据库表；沿用当前通用记录与墓碑模型。
- 不在真实用户任务上执行破坏性生产验收。

## 三、交互流程

### 删除任务

任务详情/任务中心点击删除 → 显示标题与同步说明 → 确认 → `deleteEntity('tasks', id)` → 派发 `zos:local-change` → 同步控制器上传墓碑 → 日历隐藏任务 → 显示撤销条。

### 恢复任务

回收站/撤销点击恢复 → `restoreEntity('tasks', id)` → 生成更高 revision → 派发本地变更 → 下一轮同步覆盖远端墓碑 → 任务重新显示。

### 改期任务

详情编辑或桌面拖动 → 更新任务 `startAt`/`dueAt` → 保留其余字段与时长 → 派发本地变更 → 跨端同步。

## 四、验收标准

- 新建测试任务后删除：活跃任务消失，`tasks` 墓碑存在，revision 增加。
- 同步合并遇到任务墓碑：所有端均以墓碑为准，任务不会复活。
- 恢复后：墓碑消失，任务回到活跃集合，revision 再次增加。
- 飞书/ICS/项目事件详情无删除、编辑、拖动入口。
- 任务详情提供完成、编辑、复制、改期、删除；任务中心提供删除。
- 过滤器在日/周/月/列表视图一致生效。
- 本地全量测试连续三轮通过；正式 URL 在桌面、平板、手机三轮可打开、可交互、无横向溢出。
