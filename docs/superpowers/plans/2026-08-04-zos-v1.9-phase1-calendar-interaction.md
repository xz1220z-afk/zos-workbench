# ZOS v1.9 Phase 1：智能日历交互与重要日期迁移

> 设计依据：`docs/superpowers/specs/2026-08-04-zos-v1.9-reliable-schedule-design.md`

## 目标

完成一个适合电脑、平板与手机的统一“新增安排”入口：月视图支持单击一天、拖选连续日期；拖选后可建立任务或日程；倒数日从日历移出，分别进入工作首页的“关键期限”和生活首页的“重要日子”。所有本地数据继续走现有 `state-store`，不在选择阶段写入。
