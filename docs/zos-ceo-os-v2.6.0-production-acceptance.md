# ZOS CEO OS v2.6.0 生产验收

日期：2026-08-08
发布前回滚标签：`zos-workbench-v2.5.0`

## 范围

- 导航单次渲染与低干扰页面过渡。
- 工作/生活首页的动态摘要与渐进式玻璃材质。
- 万嘉历史时间范围与口径保护界面。

## 验收标准

1. 点击任意导航仅触发一次页面渲染；筛选历史范围只触发一次状态提交。
2. 桌面、平板、手机下正文非空、无页面级横向溢出、控制台无 error。
3. 没有已校验历史数据时显示“历史数据积累中”，不展示模拟 GMV 或趋势。
4. 周期快照/未知口径显示“口径不可累计”，不直接累计。
5. 正式站的 `index.html`、`manifest.json`、`sw.js`、`src/app.mjs` 均为 `2.6.0`。

## 回滚

仅回滚前端代码到 `zos-workbench-v2.5.0`，并以新缓存版本发布；保留所有用户本机数据、云端记录和历史数据仓。
