# ZOS CEO OS v2.8.2 发布说明

发布日期：2026-08-14

## 目标

减少工作台点击后的闪动与等待感，使当前页面内操作具有更直接的反馈。

## 变更

- 将应用视图调度从“每次操作重绘所有页面”改为“只重绘当前页面”。
- 万嘉页四个语境切换只更新万嘉总控台及既有商家诊断区域。
- 页面首次进入与页面切换仍读取最新状态，不改变导航与数据模型。
- PWA 资源世代统一为 `2.8.2`。

## 安全与数据

- 不写飞书，不修改 Supabase 业务数据和万嘉历史数据仓。
- 不删除、不迁移任务、日历、收集箱、决策、Agent 上下文或私密生活记录。
- 升级前仍由既有机制生成本机保护快照。

## 回滚

回到 `zos-workbench-v2.8.1` 标签，提高缓存版本并重新发布。数据无须回滚。
