# ZOS CEO OS v2.8.3 发布说明

发布日期：2026-08-14

## 目标

完成交互性能的第二层收敛，让万嘉驾驶舱的语境切换不再重建整个页面和整套工作台数据模型。

## 变更

- 万嘉四个语境切换只替换当前内容面板。
- 万嘉当前页只计算万嘉经营与商家诊断所需数据。
- 数据未变化时复用万嘉经营模型；数据源或筛选变化后自动失效重算。
- 设置、隐私等旧页面不再触发模块化工作区计算。
- PWA 资源世代统一为 `2.8.3`。

## 安全与数据

- 不写飞书，不修改 Supabase 业务数据和万嘉历史数据仓。
- 不删除、不迁移任务、日历、收集箱、决策、Agent 上下文或私密生活记录。
- 2.8.2 中间发布保留独立 Git 提交，可追溯、可回滚。

## 回滚

回到 `zos-workbench-v2.8.2` 或 `zos-workbench-v2.8.1` 标签，提高缓存版本并重新发布。用户数据无须回滚。
