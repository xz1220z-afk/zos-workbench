# ZOS CEO Operating System v2.7.2 发布说明

## 发布范围

- 修复万嘉“查询历史”在历史仓尚无已校验数据时没有任何可见反馈的问题。
- 明确区分“查询已应用但暂无数据”与“已按当前条件更新”，避免运营人员误以为按钮失效。
- 将 PWA 缓存、入口、静态清单与模块版本统一升级到 `v2.7.2`。

## 数据与安全边界

- 本次不连接、导入或修改本机 SQLite；静态 GitHub Pages 不能直接访问 Mac 本地历史仓。
- 本次不修改 Vault、飞书、Supabase 数据库、任务、日历或用户记录。
- 没有已校验历史数据时，页面保持“数据积累中”，不生成 0 值、趋势、排行或模拟经营结果。

## 当前限制与后续接入条件

真实历史分析仍需要受保护的只读适配器，把经过校验的 SQLite `merchant_daily` / `merchant_latest` 数据以历史信封返回给已登录工作台。接入前需先确认来源文件、商家 ID、业务日期、行数与指标口径；飞书仅用于协作和展示，不替代完整历史仓。

## 备份与回滚

- 正式验收后创建 `zos-workbench-v2.7.2` Git 标签，作为代码快照。
- 不迁移或清空浏览器、本机或云端用户数据。
- 若需回滚，从 `zos-workbench-v2.7.1` 建立新的回滚提交，提升缓存版本后重新回归与生产资源回读；不强推、不删除用户记录。
