# ZOS CEO OS v2.9.0 发布记录

发布日期：2026-08-15

## 本次增量

- 现有工作首页增加 AI 指令首屏，支持键盘、点击麦克风与按住说话。
- 指令动态路由到当前业务事实、Enterprise Brain 知识入口、日历、情报或 Agent OS。
- 输出固定区分事实、推断、建议、待确认与下一步。
- C 级受控执行：只读可直达，本机草稿可撤销，外部写入只预览并等待明确确认。
- 新增模块纳入四端 PWA 离线缓存；现有导航、数据模型和用户数据保持不变。

## 隐私与权限

- 不持续监听，不后台录音，不保存原始音频。
- 不把完整语音文本、AI 回答或原始知识正文写入安全活动记录。
- 不自动写飞书、发送消息、发布内容、创建外部日历、删除或付款。

## 验收门槛

- 自动化全量通过，PWA 模块图完整，版本引用全部为 `2.9.0`。
- 桌面、平板、手机首屏正文非空且无横向溢出。
- 点击与按住语音路径可达；不支持语音时键盘输入不受影响。
- 正式站的 `index.html`、`manifest.json`、`sw.js` 与新增模块全部回读为 `2.9.0`。

## 回滚

回到 `zos-workbench-v2.8.4` 标签，并以新的缓存版本重新发布。用户任务、收集箱、日历、决策、Agent 上下文、业务只读数据和 Vault 均无须回滚。
