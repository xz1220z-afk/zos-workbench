# ZOS CEO Operating System v2.7.1 发布说明

## 发布范围

- 解决万嘉只读汇总成功后因浏览器缓存空间告警造成的误导性失败体验。
- 防止来源不完整时误将未出现的开放决策批量归档，并降低历史记录对当前待办的干扰。
- 修复情报卡打开和“标记已读”等人工操作的即时反馈。
- 增加本人主动触发的当前位置天气；定位只供当前天气请求使用。

## 数据与安全边界

- 万嘉读取仍是只读；浏览器精简副本不是实时经营事实源。
- 不完整来源不会改变开放决策状态；已经存在的历史记录不会被删除。
- 天气定位必须由本人点击并接受浏览器权限，系统不保存坐标、地址、轨迹或定位历史。
- 情报操作不写飞书、不发送消息；“转为行动”仍为工作台内的人工后续入口。

## 备份与回滚

- 正式验收后创建 `zos-workbench-v2.7.1` Git 标签，作为代码快照。
- 用户生成的数据继续使用既有本机检查点、安全导出和本人私有云同步；本次不迁移、不清空浏览器存储。
- 若需回滚，从 `zos-workbench-v2.7.0` 建立新的回滚提交，并再次提升 Service Worker 缓存版本；不得强推或删除用户记录。

## 当前限制

- 浏览器可能拒绝定位或无法获取位置；此时保留已选城市天气并说明原因。
- 本机可用空间极低时，万嘉只读数据仍可在当前页面使用，但离线副本可能无法保存；关闭页面后需要重新刷新。
