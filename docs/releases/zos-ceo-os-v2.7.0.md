# ZOS CEO Operating System v2.7.0 发布说明

## 发布范围

- 在现有 Agent OS 中增加受控派任务、本机规则快照、只读分析记录和显式确认的上下文候选。
- 调整现有生活首页的信息层级；不替换路由、左侧导航、日历、任务或公司模块。
- Agent OS 索引、任务档案、上下文候选与 REL-001 私密记录均维持本机存储，不上传 Supabase。

## 使用边界

- “派任务”只把 Agent 身份和最小引用带入现有任务输入；保存任务不代表执行、派单或外发。
- “开始只读分析”只会在 AI 服务已配置、Agent 非私密时请求分析；不写飞书、Vault、日历、消息、付款或权限。
- 只有本人确认的上下文摘要会在该 Agent 后续只读分析中使用；原始聊天、正文、定位、密码、医疗和财务字段被拒绝写入。

## 备份与回滚

- 每次正式版本必须保留：Git 提交、发布标签、变更日志、验收记录与生产回读证据。
- 数据仍保留在既有本机耐久层；本次不迁移或删除用户记录。
- 若需回滚，切回发布前的 Git 标签或提交，并以本机安全备份恢复；不得通过清空浏览器存储来回退。

## 当前限制

- 静态网页无法直接读取任意本机 Vault 路径，因此 Agent 身份卡继续通过只读索引文件导入；不把 Vault 原文公开到 GitHub Pages。
- 生产状态、标签与 HTTP 回读将在部署后写入验收记录，未回读前不宣称已上线。
