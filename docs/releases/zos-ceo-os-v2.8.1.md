# ZOS CEO Operating System v2.8.1 发布说明

## 发布范围

- 延续现有 ZOS 与万嘉 `#local-life` 页面，不新建工作台、不改导航或业务数据结构。
- 完成万嘉历史经营数据的完整、认证、只读接入；回读当前设备的 Agent OS 可调用链路。

## 万嘉历史数据

- Edge Function 使用当前登录用户 ID 显式限制历史批次，并分页读取全部允许字段。
- 已验证数据覆盖 2026-01-31 至 2026-08-08，共 10 个批次、3518 条商家快照，口径均为 `period_snapshot`。
- 周期快照不跨日期相加；区间变化只在结束日快照和开始日前基线均存在时计算。条件不足时显示 `insufficient_history / 历史数据积累中`，不显示 0 或模拟趋势。

## Agent OS

- 当前设备已导入 21 个 Agent、12 个 Skill、6 个 Workflow、12 个评估、5 个日志和 7 个 Runbook 的只读索引。
- 已验证 Agent 详情可展示使命、边界、Skill、知识入口与调用示例；Jarvis 可把专属规则和固定输出格式带入既有任务草案。
- 索引仍为本机私有数据；本次不上传 Vault 正文、不保存测试任务、不自动外发或执行。

## 回滚

- 代码回滚基线为 `zos-workbench-v2.8.0`；必须通过新提交提升 PWA 缓存版本后重新发布。
- 回滚只影响代码和展示，不删除或修改 Supabase 历史快照、飞书、Vault、Agent 身份卡或用户数据。
