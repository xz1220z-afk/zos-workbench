# ZOS CEO OS v2.12.0 发布记录

**日期：** 2026-08-16  
**范围：** 在现有 ZOS 工作台内增量加入 AI Office 经营闭环，不替换导航、Agent 身份、任务、知识库或用户数据。

## 本次新增

- Agent 页面新增“AI Office 实时席位”，状态由 Agent 身份卡与最近任务/运行记录动态计算，不把设计中的 Agent 伪装成已运行。
- 新增能力与权限注册表，明确文字问答、快捷语音、实时语音、知识引用与外部动作的可用状态和确认边界。
- 新增统一执行台账，汇总安全的 AI 活动、Agent 运行、任务归档和待确认动作；不保存原始语音、完整提示词、回答正文、知识正文或密钥。
- 工作首页新增“AI 推进提醒”，从逾期任务、目标缺口、已完成 Agent 结果和未落地的 AI 下一步中生成有限条提醒。
- 私密关系 Agent 仅在私密关系筛选中展示，公共区域只显示脱敏状态。
- PWA 入口、浏览器模块、清单和 Service Worker 缓存世代统一升级为 `2.12.0`。

## 数据与权限边界

- 只复用现有任务草稿、Agent、AI 助手、语音和确认流程。
- “生成任务草案”只打开已有任务编辑入口，不自动保存、不自动派单。
- 飞书写入、消息发送、发布、付款、删除和权限变更继续停留在预览/待确认状态。
- 本次不迁移、不删除、不覆盖既有本地或云端数据。

## 备份与回读

- 发布前代码回滚点：`zos-workbench-v2.11.0-pre-ai-office`。
- 工作台继续沿用版本升级前的本机保护快照与现有跨端同步机制。
- 发布后回读 `index.html`、`manifest.json`、`sw.js` 与代表性模块，确认均为 `2.12.0` 且 HTTP 200。

## 回滚

1. 将发布分支回退到标签 `zos-workbench-v2.11.0-pre-ai-office`。
2. 使用新的 Service Worker 缓存世代重新发布，避免客户端混用两个版本。
3. 不删除或回写任务、Agent、日历、同步记录和三家公司经营数据。
