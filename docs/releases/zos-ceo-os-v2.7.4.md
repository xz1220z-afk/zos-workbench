# ZOS CEO Operating System v2.7.4 发布说明

## 发布范围

- 修复“设置 → 立即同步”在已登录状态下仍调用旧兼容同步逻辑的问题。
- 保持既有导航、设置页、Supabase 登录流程与用户数据结构；不创建第二套工作台。

## 修复说明

- 页面启动后会把设置页的同步入口桥接到已登录的 CEO OS 同步控制器。
- 该控制器只维护当前工作台状态，不会再将完整收集箱额外复制到旧 `zos_inbox` localStorage 键。
- 未建立会话时，按钮仍回退到原登录路径，不会把“未登录”伪装为已同步。

## 数据与安全边界

- 本次不删除、清空、压缩或迁移任务、收集箱、项目、日历、决策、Supabase 用户记录、万嘉历史快照、飞书或 Vault 内容。
- 万嘉历史读取仍必须走认证态接口，`period_snapshot` 仍不可按日期直接求和。

## 回滚

- 若需撤回代码，以 `zos-workbench-v2.7.3` 为基线创建新的回滚提交，并再次提升 PWA 缓存版本后发布。
- 回滚只作用于前端代码和缓存，不删除或改写任何用户记录与历史数据仓。
