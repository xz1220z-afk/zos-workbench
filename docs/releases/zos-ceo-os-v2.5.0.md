# ZOS CEO Operating System v2.5.0

发布日期：2026-08-08  
类型：增量发布；保留既有页面、导航、数据结构与本地数据。

## 本版变更

- 日历中心默认打开月视图；日、周、列表仍由用户手动切换。
- 情报问答与 Agent 工作台新增受控的 OpenAI 只读分析入口。
- Agent 调用保留原有“任务草稿”入口；直接分析不会执行外部动作或写入业务系统。
- 新增手动导入的知识摘要索引：只接受用户选择的短摘要、标题、标签与来源引用，不上传 Vault 正文。
- 新增阳西天气概览；使用公开预报接口，不请求浏览器定位。
- REL-001 等私密关系 Agent 仅保留本地私密提醒草稿，不向云端 AI 分析接口发送内容。

## 数据与安全边界

- OpenAI API 密钥只可保存在 Supabase Edge Function Secret `OPENAI_API_KEY`，不进入网页、仓库或本地数据备份。
- 若未配置该 Secret，界面必须明确显示“AI 服务尚未配置”，不得伪造回答。
- 飞书、Vault、日历、消息和任务的写入/外发均维持原有确认门槛。

## 回读与回滚

- Git 提交和标签 `zos-workbench-v2.5.0` 是本版本代码备份锚点。
- 回滚时将 GitHub Pages 的 `main` 回退至 `zos-workbench-v2.4.0` 标签对应提交；不删除用户浏览器本地数据、Supabase 已有业务数据或 Vault 内容。
- 每次后续功能发布应附一份对应版本说明、测试结果与回滚锚点。
