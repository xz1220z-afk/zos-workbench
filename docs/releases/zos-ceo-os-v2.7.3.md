# ZOS CEO Operating System v2.7.3 发布说明

## 发布范围

- 在既有万嘉网络页面接入受保护的历史读取：`zos-business-data?source=wanjia&history=1`。
- 保留现有导航、页面结构和用户数据；不新建第二个工作台。
- 历史区显示已验证状态、时间筛选、每日快照趋势和单商家历史明细。

## 数据口径与安全

- 适配器只允许已验证批次和已授权字段进入前端；查询必须经过已有 Supabase 登录闸门。
- 当前 `period_snapshot` 不可按日期相加。页面将每一天标为快照，并使用结束日快照减开始日前最近快照计算区间变化。
- 没有起点快照时状态为 `insufficient_history`，页面不把它显示成业绩为 0，也不补造趋势或排行。
- 历史读取不展示原始文件、哈希、密钥或 raw JSON；不写飞书、Vault、任务或用户记录。

## 当前数据边界

- 本次接入针对已存在、已验证的 2026-08-07 至 2026-08-08 两个批次。数据仓的更长历史仍会以“历史数据积累中”明确呈现，直到存在可计算的起点快照。

## 回滚

- 若需撤回代码，使用 `zos-workbench-v2.7.2` 建立新的回滚提交并提高缓存版本后重新部署。
- 不删除或改写 Supabase 历史批次、商家明细、浏览器用户数据、Vault 或飞书记录。
