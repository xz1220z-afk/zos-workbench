# ZOS CEO OS v2.12.1 发布记录

**日期：** 2026-08-17  
**范围：** 修复工作首页决策计数、AI 故障提示和实时语音能力状态；不改变导航、数据结构或用户记录。

## 本次修复

- 工作首页只统计当前未处理且需要本人判断的决策，343 条已处理历史不再进入“今天需要拍板”。
- AI 请求失败时保留用户输入和 Chrome 已具备的实时语音能力，不再把服务故障误报为浏览器不支持。
- AI 与实时语音 Edge Function 将上游失败归类为有限安全代码；前端给出额度、密钥、权限、模型和频率对应的操作提示。
- PWA 入口、manifest、浏览器模块查询参数和 Service Worker 缓存世代统一升级为 `2.12.1`。

## 数据与安全边界

- 不删除、不迁移、不覆盖决策历史、任务、日历、Agent、知识库或三家公司经营数据。
- 不把 OpenAI 原始响应、密钥或内部故障正文返回浏览器；服务端日志只保留 HTTP 状态和安全类别。
- 飞书写入、外发、发布、付款和删除仍须屏幕明确确认。

## 备份与回滚

- 发布前代码回滚点：`zos-workbench-v2.12.0-pre-production-fixes`。
- 工作台继续使用升级前本机保护快照与既有跨端同步机制。
- 回滚时恢复上述标签并使用新的缓存世代发布；不得删除用户数据或云端记录。
