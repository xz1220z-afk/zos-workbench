# ZOS CEO Operating System v2.6.0

发布日期：2026-08-08
类型：增量发布；保留现有页面、导航、数据结构、同步与本机数据。

## 本版变更

- 修复导航点击重复调用渲染导致的页面“闪两下”；筛选历史数据时也改为单次状态提交与渲染。
- 工作首页与生活首页改为随真实待决策、待办、重要日子和仪式提醒变化的动态摘要，不再固定显示口号式标题。
- 万嘉本地生活运营总控台增加时间范围查询、数据可用性、每日趋势、商家排行和单商家时间轴。
- 新增历史指标口径保护：仅 `daily_increment`（每日新增值）可累加；周期快照或未知口径明确显示“口径不可累计”，绝不伪造趋势。

## 数据边界

- 历史权威源仍为本机 SQLite 数据仓（`merchant_daily`、`merchant_latest`、`ingest_batch`）；飞书只作为协作和展示层。
- 静态 GitHub Pages 不直接读取本机 SQLite。浏览器仅在受保护的只读适配器提供 `history` 索引后显示已校验数据；未接通时显示“历史数据积累中”，不以 0 填充。
- 本版不新增飞书写入、任务自动派单、Vault 修改或外部自动执行。

## 回读与回滚

- 发布前代码基线：`zos-workbench-v2.5.0`。
- 正式验收完成后的 Git 标签 `zos-workbench-v2.6.0` 为本版代码备份锚点。
- 如需回滚，从 v2.5.0 标签创建恢复分支并生成新的回滚提交，同时提升 Service Worker 缓存号；不删除浏览器本地数据、Supabase 数据、飞书记录或 Vault 内容。
