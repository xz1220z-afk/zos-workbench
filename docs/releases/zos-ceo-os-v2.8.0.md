# ZOS CEO Operating System v2.8.0 发布说明

## 发布范围

- 仅增量升级既有万嘉网络页面 `#local-life`。
- 保留左侧导航、花火、玲丽、财务、任务、现有万嘉数据结构与全部用户记录；不创建第二套工作台。

## 页面调整

- 新增四个清晰语境：**今日总控、商家作战、增长复盘、数据分析**。
- 默认总控只显示经校验的当前经营事实、规则识别的待处理商家和增长机会。
- 商家作战保留健康筛选、商家明细、诊断和“任务草案”入口；草案不会自动派单或写入飞书。
- 增长复盘在历史基线不足、周期快照不可累计时显示数据口径限制，不编造增长、下滑、排行或业绩结论。
- 历史范围、快照趋势、排行和单商家时间线保留在数据分析语境，明确与今日事实隔离。

## 数据与安全边界

- 本次未修改飞书、Supabase、SQLite、商家资料、历史快照、任务、日历、Vault 或任何用户数据。
- 历史 `period_snapshot` 仍只读，禁止直接跨日期求和；缺少起点快照继续显示“历史数据积累中 / insufficient_history”。

## 回滚

- 如需撤回代码，以 `zos-workbench-v2.7.4` 为基线建立新的回滚提交，提升 PWA 缓存版本后重新发布。
- 回滚只作用于前端代码与缓存，不删除或改写经营历史、飞书记录或用户数据。
