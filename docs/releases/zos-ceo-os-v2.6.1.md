# ZOS CEO Operating System v2.6.1

发布日期：2026-08-08
类型：可靠性修复；不改变既有页面、路由、事实源或用户数据。

## 本版变更

- 修复万嘉、花火与企业大脑的只读业务缓存超过浏览器本机容量时，页面把缓存异常误报为“数据读取失败”的问题。
- 新增配额安全缓存：先保留本次已读取的完整数据供当前页面使用；仅在需要时保存精简的只读副本；精简副本仍无法保存时，明确提示“本机缓存提示”，不会把成功的业务读取改判为失败。
- 不会自动清空浏览器存储，也不会删除任务、日历、Agent、知识索引、飞书、Supabase、Vault 或本地 SQLite 历史数据。

## 数据与安全边界

- 该修复只处理浏览器本机缓存。飞书 ERP、受保护的 Supabase 只读接口和本机 SQLite 历史仓仍分别保持原有事实源边界。
- 精简缓存不保存原始正文、完整载荷、附件、多媒体或大字段；下一次打开页面仍以当前受保护数据源为准。
- 本版不新增外部写入、自动派单、消息发送、发布、日历创建或权限变更。

## 回读与回滚

- 发布前代码基线：`zos-workbench-v2.6.0`。
- 正式验收后创建标签 `zos-workbench-v2.6.1`，作为本版代码备份锚点。
- 需要回滚时，从 `zos-workbench-v2.6.0` 建立恢复提交并以新的 Service Worker 缓存版本发布；保留所有浏览器本机数据、云端记录、飞书记录、Vault 文件和 SQLite 数据仓。
