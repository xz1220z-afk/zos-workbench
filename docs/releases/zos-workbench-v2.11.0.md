# ZOS CEO OS v2.11.0 发布记录

候选日期：2026-08-16  
状态：发布候选，尚未完成生产验收。

## 本次范围

- 独立老板登录页：四端在认证与老板授权完成前不启动业务、知识库、Agent 或同步运行时。
- 认证记忆：只记住用户主动选择的邮箱与 Supabase 会话；密码交给浏览器/系统密码管理器，工作台不保存。
- 实时同步：Supabase Realtime 只作为变更信号，随后复用既有权威拉取、合并、冲突与墓碑规则；保留定时、联网和前台恢复兜底。
- 快捷语音：本人点击/按住后转写并提交既有 AI 分析；无语音权限时保留键盘入口。
- ChatGPT 实时语音：本人手势启动 WebRTC 会话，支持字幕、静音、打断、结束、一次受控重连、90 秒空闲确认和 15 分钟硬上限。

## 权限、数据与隐私边界

- 全局公司数据、AI 和飞书审批端点只允许 `ZOS_OWNER_USER_ID` 指定的老板账号；匿名为 401，已登录非老板为 403。
- `zos_records` 继续由 `auth.uid() = user_id` 的 RLS 隔离；Realtime 不扩大读取范围。
- OpenAI API 密钥和 Supabase 服务端密钥不进入浏览器、PWA 缓存、日志或发布文档。
- 实时语音不保存原始音频；只按任务需要发送允许的上下文和经批准知识摘要。
- AI 可搜索、分析、草拟和生成审批预览；不得自动发送消息、写飞书、发布、删除、付款或执行高影响动作。
- 本次迁移不删除、不改写现有用户记录；本机数据、云端记录、飞书、Vault 与历史快照保持原有事实边界。

## 发布与回滚

- 目标 PWA 版本：`2.11.0`。
- 发布前代码恢复点：`zos-workbench-v2.10.0-pre-owner-auth`。
- PWA 回滚必须基于恢复点提升一个新的缓存世代后重新发布，不能让旧 Service Worker 与新模块混用。
- 实时语音异常时只停用 `zos-ai-realtime-session` 入口；快捷语音和键盘仍可使用。
- Realtime 异常时客户端继续使用定时、联网、前台刷新；如需移除 publication 成员，必须通过另行审核的回滚迁移，RLS 保持启用。
- 禁止以清空 localStorage、删除云端行或重置飞书数据作为回滚方式。
