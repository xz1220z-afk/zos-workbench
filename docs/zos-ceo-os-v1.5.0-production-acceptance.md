## 回滚

1. 若云端任务异常，先停用 `zos-business-refresh-15m`；浏览器仍保留逐来源手动刷新。
2. 若服务端新版本异常，重新部署上一已验证版本的三个 Edge Function；保留只读缓存表，不删除历史缓存。
3. 若前端异常，回退 GitHub Pages 到 v1.4.3；Service Worker 会随旧版本缓存名重新接管。
4. 回滚不修改飞书表结构、不删除飞书记录，也不改变现有人工确认写入流程。
